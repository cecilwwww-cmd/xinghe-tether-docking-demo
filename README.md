# 星河注能｜顶置三绳系绳罩概念验证

这是一个纯静态、可交互的Three.js概念验证页面，用于展示：

- 顶置系绳罩按六个侧面接口方向转位；
- 固定内环与旋转外环驱动三条系绳同步收拢；
- 捕获后目标的牵引路径；
- 顶部直接斜拉与面中心导向器的轴线误差差异；
- 轴向导管对俯仰/偏航的几何约束，以及滚转仍需键控或姿态控制的边界。

## 使用方法

直接打开在线页面。选择目标平面、初始轴线误差和牵引路径，再依次点击“顶部转位—罩盖打开—三绳捕获—拉近—面上对接”。拖拽模型旋转视角，滚轮缩放。

## 本地查看

此页面只包含静态文件。可直接打开 `index.html`；若浏览器限制模块加载，也可在本目录启动任意静态文件服务器。

## 工程边界

该页面用于概念与几何验证，不代表飞行级设计或在轨验证。当前尚未闭合的问题包括：

- 系绳仅能承受拉力导致的六自由度欠驱动；
- 柔性系绳动力学、振动、松弛、碰撞和张力分配；
- 捕获后的滚转对准、锁紧、密封和载荷转移；
- 传感噪声、时延、热变形与真实空间环境下的可靠性。

工程主线仍建议采用机械臂宏定位与六自由度并联平台微调；本方案作为扩大捕获域的探索性路线。
